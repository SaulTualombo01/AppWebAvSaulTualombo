## Clon Spotify "PoliMusic" en ASP clasico (VBScript)
- Construido sitio completo restringido al script BDD_PoliMusic.sql (sin tablas nuevas).
- Stack: ASP clasico + VBScript + ADODB (SQLOLEDB), SQL Server localhost, login usr_polimusic / Politecnica1, BDD BDD_PoliMusic (verificada: 5 canciones, 3 usuarios).
- Roles: USER_TYPE 1=admin (CRUD canciones/artistas/albumes + tracklist), 0=normal (CRUD playlists propias + canciones).
- Login soporta password plano y SHA1 mayusculas via HASHBYTES en SQL Server (seed usa SHA1 de "12345678" para username1).
- Diseno: lavanda (#e6e6fa/#b57edc) sobre ciruela oscuro + ambar (#f5c66b) complementario; player fijo al pie con <audio> y fetch a play_count.asp.
- Assets: recursos copiados a songFiles/, PlaylistImages/, UserImages/; mp3 duplicado a los 5 nombres esperados; albumImages/ArtistImages/ pobladas con los png disponibles; placeholder images/no-cover.svg.
- Nota: rutas "~/x" de la BDD se resuelven con funcion WebPath/ImgPath (includes/db.asp); Response.End agregado tras Redirects (ASP no detiene ejecucion solo).
